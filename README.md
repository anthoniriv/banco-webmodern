## Qué hace

Una landing page para presentar los servicios de un banco moderno. Diseño limpio y profesional, totalmente responsive, con elementos interactivos y animaciones. Sirve como base o demo para proyectos de fintech/landing.

## Funcionalidades

- Diseño moderno y profesional, responsive para escritorio y móvil.
- Menú con dropdowns y animaciones.
- Secciones informativas: features, clientes, testimonios y estadísticas.
- Formulario de contacto.
- Construcción con componentes reutilizables (Atomic Design).

## Uso local

```bash
npm install
npm run dev      # http://localhost:5173
```

Build de producción (genera `dist/`):

```bash
npm run build
```
